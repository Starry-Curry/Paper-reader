# 双栏导师阅读器规范

## 定位

`guided-reader.html` 是论文阅读包的默认特色产物：

- 左栏：面向初学者的导师详解；
- 右栏：与左栏语义对齐的英文原文；
- 窄屏：左栏在上、右栏在下；
- 中文连续译文仍由 `translated-paper.html` 单独提供。

它不是把 `index.html` 和整篇 PDF 并排放置，也不是英文/中文逐句翻译页。每一行应让读者先理解一个问题，再核对作者实际如何表述。

## 内容选择

覆盖论文论证主线中的关键原文：

- 摘要和问题定义；
- 方法总览；
- 每个锚点公式附近的原文；
- 训练与推理描述；
- 关键实验和作者结论；
- 会改变理解边界的附录段落。

可以按语义段落合并断栏文本，但不能改写右栏英文。省略非关键段落时，在页面说明覆盖范围，不得声称逐段全文对照。

## 每个对齐行

每行使用：

```html
<div class="guided-row" data-source-anchor="§3.2 · p.4 · Eq. (9)">
  <aside data-role="mentor">...</aside>
  <article data-role="source" lang="en">...</article>
</div>
```

左栏优先回答：

1. 这段接着前文解决什么问题；
2. 阅读它需要补哪个前置概念；
3. 公式或算法到底怎样执行；
4. 哪一句是作者主张，哪一句只是动机；
5. 读完后应该带走什么；
6. 容易误读在哪里。

右栏保留：

- 原始术语和限定词；
- 公式、变量与编号；
- 引用编号；
- Figure/Table/Appendix 指代；
- 段落中的否定、可能性与比较条件。

## 公式行

当右栏包含锚点公式时，左栏不要只重复符号表。至少加入：

- 公式朗读；
- 一个最小例子或极端情况；
- 它在训练/推理中的位置；
- 公式来源状态；
- 一个常见误解。

详细推导可链接到 `index.html` 的对应公式锚点。

## 页面与交互

- 双栏宽度默认接近 1:1；公式很密集时右栏可略宽。
- 保留章节目录、阅读进度、来源锚点和返回教程/译文/笔记的入口。
- 正文不依赖 JavaScript 才能出现。
- 右栏使用不同但不过度降低对比度的纸张背景。
- 360–430 px 下改单列，不能出现整页横向滚动；单个公式允许局部滚动。
- 使用本地 CSS 和图片，不加载远程字体或运行时库。

## 完成检查

- `guided-reader.html` 存在并可离线打开；
- 左右栏行数一致；
- 每行同时包含 `data-role="mentor"` 与 `data-role="source"`；
- 所有行拥有来源锚点；
- 右栏确有英文原文，而不是中文译文或摘要；
- 锚点公式在左栏获得公式精讲；
- 页面明确声明覆盖范围；
- 窄屏媒体查询可将双栏改为单栏；
- 本地链接、图片与样式无断链。
